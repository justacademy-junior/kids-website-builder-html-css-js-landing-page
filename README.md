# Kids Website Builder: HTML, CSS and JavaScript Landing Page

A playful, responsive landing page that answers one question: **How can kids create their own educational website using HTML, CSS and JavaScript?**

It includes a live mini website builder, a "house" explainer for the three languages, a 4-week learning plan, a quick quiz and parent safety tips. It is a single `index.html` file with no frameworks and no build step.

## Features

- Live builder: change a title, colour and mascot and watch the page and code update
- HTML, CSS and JavaScript explained as walls, paint and power
- Interactive 4-week plan tabs and a mini quiz
- Responsive layout, sticky header, card design and full footer
- Keyboard focus styles and reduced-motion support

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

## Publish free with GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch.
2. Go to **Settings > Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.
